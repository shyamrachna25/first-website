1. Structure + my top 10 tags

My page has a navbar at the top, a main part with headers and sections, and a footer at the bottom. Here are the 10 HTML tags I think are the most useful (at least for now, since I'm still learning):

  1. div - basically a box you can put anything in, I use it everywhere
  2. span - like a div but doesn't go to a new line
  3. section - groups content together, kind of like div but more "meaningful"
  4. nav - for navigation links like my navbar up top
  5. ul and li - for lists (I used this one for this exact list lol)
  6. a - for links, obviously very important
  7. img - to put pictures on the page (need to remember alt text)
  8. h1, h2, h3 - headings, to organize the page
  9. button - for anything clickable
  10. p - paragraphs, for normal text

2. SEO tags

I looked up SEO and found these tags matter the most:

  • <title> - shows up as the clickable headline on Google
  • <meta name="description"> - the little summary under the title on Google
  • <h1> - should only be used once per page
  • <h2> and <h3> - help organize the page so Google understands it better
  • alt text on images - helps Google know what the image is
  • <meta name="viewport"> - tells Google your site works on mobile

5. Font sizes (inline style)

  • Reading is fundamental - 12px, this is px which is a fixed size, good for small print like a copyright notice
  • Reading is fundamental - 24px, also fixed size px, good for something like a button text that should always be the same
  • Reading is fundamental - 1.5em, this is relative to the parent element's font size
  • Reading is fundamental - 2rem, relative to the root html font size, good for headings
  • Reading is fundamental - 3vw, relative to the browser width, so it changes when you resize the window
  • Reading is fundamental - 120%, relative to parent font-size like em but as a percent
